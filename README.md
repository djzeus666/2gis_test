# Генератор сайтов и КП для организаций из 2GIS

Система автоматической генерации интерактивных сайтов-демонстраций (портфолио) для организаций, собранных с сайта 2GIS, с удобной панелью управления и генератором коммерческих предложений (КП).

---

## 🚀 Основные возможности

1. **Импорт данных из 2GIS:**
   - Поддержка файлов в формате **CSV** (с разделителями `,` или `;`) и **JSON**.
   - Автоматическая распознаваемость русскоязычных и англоязычных заголовков колонок (`Название`, `Категория`, `Город`, `Телефон`, `Адрес`, `Описание` и др.).
   - Автоматическая нормализация рубрик 2GIS по основным тематическим категориям:
     - 🚗 Автосервисы и СТО (`auto`)
     - 🏗️ Строительство и ремонт (`construction`)
     - 🛍️ Магазины и ритейл (`store`)
     - 💇‍♀️ Салоны красоты и барбершопы (`beauty`)
     - 🏥 Медицинские центры и клиники (`medical`)
     - 🏢 Общие услуги (`general`)

2. **Динамическая генерация лендингов (`/demo/{id}`):**
   - Уникальный дизайн, цветовая гамма, иконки, баннеры и блоки услуг под каждую категорию бизнеса.
   - Адаптивная верстка на Tailwind CSS.
   - Персонализированные данные организации из 2GIS (название, контакты, город, адрес, режим работы, описание).
   - Плавающая шапка с кнопкой быстрого заказа сайта.

3. **Панель управления и рассылка КП (`/`):**
   - Загрузка файлов CSV/JSON в пару кликов.
   - Просмотр списка всех импортированных организаций.
   - Быстрый переход к сгенерированному лендингу-примеру.
   - **Копирование КП в 1 клик:** Готовый персонализированный текст коммерческого предложения со ссылкой на пример сайта для отправки в мессенджеры или на email.
   - Функция очистки базы данных.

---

## 🛠️ Стек технологий

- **Backend:** Python 3.12, FastAPI, SQLAlchemy, SQLite
- **Frontend & Templates:** Jinja2, HTML5, Tailwind CSS
- **Containerization:** Docker, Docker Compose

## 💻 Быстрый запуск

### Вариант 1: Запуск через Docker Compose (рекомендуется)

1. Убедитесь, что установлены [Docker](https://www.docker.com/) и Docker Compose.
2. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <repository_url>
   cd <repository_folder>
   ```
3. Запустите контейнеры:
   ```bash
   docker-compose up --build -d
   ```
4. Откройте панель управления в браузере:
   ```
   http://localhost:8000
   ```

---

### Вариант 2: Локальный запуск (без Docker)

1. Убедитесь, что у вас установлен **Python 3.10+**.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Linux/macOS
   # venv\Scripts\activate   # На Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите сервер Uvicorn:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
5. Перейдите в браузере по адресу `http://localhost:8000`.
